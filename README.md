# TheOnlyException
- we are the only exception (cring)

A roguelike survival game inspired by **SoulKnight** and **HoloCure**, built in **Java** with **JavaFX**. The game features an arena where enemies continuously spawn and chase the player, with the goal of surviving as long as possible.

## Features
- **Survival Mode**: Enemies spawn endlessly and chase the player.
- **Combat System**: Use melee and ranged attacks to defend yourself.
- **Health System**: Taking damage from enemies reduces health; the game ends when health reaches zero.
- **Arena Mechanics**: A limited battlefield where enemies spawn from the edges.

## Tech Stack
- **Java** (Object-Oriented Programming, Generics, Multithreading)
- **JavaFX** (Graphical User Interface)
- **Data Structures & Algorithms** (Lists, Queues, Trees for enemy spawning and attacks)
- **JDBC** (Database for player stats and game progress)
